# Kaleido

Three-oscillator all-round synthesizer (VST3 + Standalone for Windows) with 51 presets.

## Upload and build
1. New GitHub repository (Public) > "uploading an existing file" > drag in ALL files from this folder > Commit.
2. Click build.yml > pencil icon > type `.github/workflows/` right before "build.yml" in the name field > Commit.
3. Actions tab > wait for the green check > download "Kaleido-Windows" > copy "Kaleido.vst3" to C:\Program Files\Common Files\VST3.

## Pages
- Synth: 3 oscillators with 13 models each, cross FM, ring mod, 7 filter types, envelopes, voice mode.
- Modulation: 2 LFOs (8 waves), looping mod envelope, 4 mod slots, Strange physics (gravity, entropy, drift, orbit).
- Arpeggiator: off by default. 12 patterns, 10 rhythms, swing, ratchets, octave jumps, latch.
- Effects: drive, tape, stereo chorus, stereo phaser, synced ping-pong delay, granular cloud,
  shimmer reverb, rhythm gate, auto-pan, Haas, width.
